## 제거된 클래스: Bodypanel-Dent (2026-08-04)

원본 Roboflow 데이터셋의 **라벨링 오류**로 판명되어 제거함.

- 전체 203개 인스턴스가 단 하나의 원본 사진(`IMG_0952_JPG`)에서 나온 것이었고, 이걸 `augment.py`가 200개로 증강해 부풀렸던 것
- 그 원본 라벨의 바운딩박스가 (1127,138)~(1128,140), 즉 **가로 1px x 세로 2px** — 사진 속 차체가 아니라 배경(매장 건물 근처)을 가리키는 점이었음. 실제로는 같은 사진에 `quaterpanel-dent`로 정상 라벨링된 진짜 손상이 따로 있었음
- 전체 203개 인스턴스의 박스 크기를 전수 조사한 결과 고유 크기 조합이 단 2가지뿐 — 전부 동일한 오류 라벨의 복제였음을 확인
- `scripts/remove_bodypanel_dent.py`(+ 후속 버그 수정용 `scripts/fix_renumber_recovery.py`)로 해당 라벨 라인 제거 및 나머지 클래스 재번호(1~16 → 0~15) 처리, `data/data.yaml`도 16종으로 갱신
- **주의**: 이 조치는 `data/` 라벨 파일을 직접 수정한 것이라, 기존에 배포된 YOLO 모델(17종 기준으로 학습됨)과 클래스 스키마가 어긋남 — 16종 기준으로 재학습 전까지는 배포 모델을 그대로 유지

## 관찰

- 덴트류가 10종/16종으로 다수 — 대부분의 학습 데이터가 찌그러짐에 쏠려 있음
- 손상 "종류"(스크래치 vs 찌그러짐 vs 파손) 구분은 없고, "부위 + 상태"가 묶인 클래스 체계임. 별도의 스크래치 클래스는 없고 덴트/파손 위주로 구성됨

## 참고

이 4개 카테고리(덴트/유리/램프/미러) 구분은 RAG 챗봇 문서 설계 시 문서 그룹핑 기준으로도 활용 가능함.
